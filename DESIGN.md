# OpenPencil — Design

## Identity

OpenPencil is an open-source, AI-native design editor: it opens and writes native `.fig`
files and its own `.pen` documents, renders with Skia, and ships as a ~7 MB Tauri desktop
app, a browser PWA, a headless Vue SDK, a scriptable CLI, and an MCP server that lets AI
agents build and edit designs directly. It is a precision instrument that happens to run
in software — the visual identity should carry the feeling of a real drafting tool: a
sharpened pencil, confident line weight, no wasted motion. Bold and crafted, not another
purple AI-chat wrapper with a gradient blob for a logo.

## Icon

The mark is a single sharpened wooden pencil, drawn as a bold faceted pictogram — the
literal object the product is named after, not an abstraction of it. It reads instantly
at any size because it is one strong diagonal shape with a handful of flat facets, the
way a pencil actually looks: hexagonal barrel, a ferrule band, a tapered wood cone,
a graphite point.

It must never become: an abstract gem/diamond/teardrop blob (the previous asset drifted
here — a pencil tip read as a jewel once the barrel was cropped away), a rounded-square
app-icon shape floating on a purple-to-orange rainbow gradient backdrop, a wordmark or
any lettered/calligraphic mark, or a generic "AI sparkle" glyph.

## Palette

- **Primary `#F2B400`** — classic pencil-yellow. The single most recognizable color
  association with the product's own name; carries the identity without needing text.
- **Accent `#FF5D8F`** — eraser pink, the pencil's other iconic material. Used for
  interactive/CTA moments against the yellow and graphite.
- **Neutral `#1C1F26`** — graphite/ink near-black, used for the ferrule, the sharpened
  point, and dark UI surfaces. Reads as "drawn," not "computed."

## Anti-goals

- No generic purple-AI-SaaS gradient background (`#A855F7` or the rainbow purple → orange
  → blue wash the previous icon asset used).
- No abstract gem/diamond/teardrop shape standing in for the pencil tip — it must read as
  a pencil, not a jewel.
- No app-icon-shaped card floating in empty margin — the pencil's own facets must fill the
  square edge to edge.
- No wordmark, no calligraphy, no lettering of any script anywhere in generated assets.
- No soft photographic gradients, glassy reflections, or drop shadows — flat, bold, high
  contrast faceted shading only.
