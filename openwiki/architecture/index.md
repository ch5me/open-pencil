# Files

- [AI, ACP, Automation, and MCP](ai-and-automation.md) - OpenPencil has separate built-in AI, desktop ACP, browser automation RPC, and MCP adapter paths that share core `ToolDef` operations where possible but have distinct transport, lifecycle, and security contracts.
- [Collaboration Sessions](collaboration.md) - Collaboration combines Trystero WebRTC for local peer rooms or a hosted Durable Object room with Yjs graph state, awareness, and IndexedDB persistence. Session setup and teardown are explicit lifecycle operations.
- [Document Lifecycle and Storage Backends](document-lifecycle.md) - Document state is owned per editor tab and mediated by backend capability contracts. Local file handles/Tauri paths, hosted document clients, autosave, reload, watchers, assets, and collaboration must preserve source identity and saved-version state.
- [Documents, SceneGraph, and Format Adapters](documents-and-formats.md) - @open-pencil/core owns the semantic SceneGraph and IORegistry; adapters translate .fig, .pen, raster, SVG, PDF, JSX, and DOM/CSS data while preserving explicit scope and round-trip invariants.
- [Editor Runtime and Session Composition](editor-runtime.md) - The browser and Tauri application start at `src/main.ts`, compose global context in `App.vue`, route through auth-aware Vue Router guards, and operate on tab-scoped `EditorStore` instances.
- [Editor UI and Interaction Layer](editor-ui.md) - The application UI binds `@open-pencil/vue` surfaces and product components to the active `EditorStore`, while shell commands, keyboard shortcuts, canvas input, property panels, and editing modes share core mutation and undo contracts.
- [Hosted API and Runtime Storage](hosted-api.md) - api/ is a private Cloudflare Worker boundary for hosted auth checks, document CRUD/assets, and Durable Object collaboration rooms. Local editor mode does not require this service.
- [OpenPencil Architecture Overview](overview.md) - OpenPencil is a Vue 3 and Tauri design editor with a headless package ecosystem, file-format tooling, AI/MCP automation, and an optional hosted API. This page defines repository boundaries and the main runtime composition.
